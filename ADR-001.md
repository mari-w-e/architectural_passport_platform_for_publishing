**Status**: accepted

**Context**: команда 3 человека, релиз за 3 месяца, нагрузка до 100к пользователей (MAU)

**Decision**: Модульный монолит с единой точкой развертывания.

Для хранения данных использовать PostgreSQL,

Redis - для кеширования и временных данных,

S3-совместимое объектное хранилище для файлов и медиаконтента.

Внешние интеграции: 
- Платежный провайдер для обработки платежей.
- Провайдер уведомлений (email) для отправки уведомлений.

**Consequences:**
  Положительные:
  - быстрый старт разработки,
  - единый deploy,
  - ACID-транзакции в PostgreSQL,
  - простое взаимодействие между модулями,
  - снижение нагрузки на основную БД благодаря Redis,
  - S3 для хранения файлов и больших объектов.

  Отрицательные:
  - масштабирование приложения только целиком,
  - отказ или сбой backend может затронуть все систему,
  - необходимость дисциплины в поддержании границ между модулями.
